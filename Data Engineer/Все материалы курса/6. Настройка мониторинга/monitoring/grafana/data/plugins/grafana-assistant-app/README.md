# Grafana Assistant

Grafana Assistant is an AI-powered observability agent built into [Grafana Cloud](https://grafana.com/products/cloud/) that helps you monitor, troubleshoot, and manage your systems through natural language conversations. Instead of learning complex query languages or memorizing dashboard locations, you can ask simple questions like "Show me CPU usage" or "Create a dashboard for my database."

The Assistant understands your observability data across metrics, logs, traces, profiles, and databases. This makes it easier to gain insights and solve problems without requiring deep technical expertise in each tool.

## What Grafana Assistant can do

Grafana Assistant acts as your observability expert, helping you work more effectively with your monitoring data through five core workflows:

- **[Data analysis and querying](https://grafana.com/docs/grafana-cloud/machine-learning/assistant/data-analysis)**: Ask questions about performance, launch investigations, and correlate metrics, logs, traces, profiles, and SQL data.
- **[Dashboard management](https://grafana.com/docs/grafana-cloud/machine-learning/assistant/dashboards)**: Create new monitoring dashboards or refine existing panels, layouts, and variables.
- **[Query assistance](https://grafana.com/docs/grafana-cloud/machine-learning/assistant/query-assistance/)**: Build and refine PromQL, LogQL, TraceQL, SQL, and k6 queries with validation and optimization tips.
- **[Navigation and discovery](https://grafana.com/docs/grafana-cloud/machine-learning/assistant/navigation/)**: Find dashboards, data sources, and related tools without leaving the conversation.
- **[Knowledge and best practices](https://grafana.com/docs/grafana-cloud/machine-learning/assistant/knowledge/)**: Ask for Grafana guidance, observability concepts, and monitoring strategies in context.
