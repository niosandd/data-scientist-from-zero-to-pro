## Шаг 1: Проверка установки Docker Desktop for Windows
- **Что должно быть прислано студентом:** Скриншот установленного Docker Desktop for Windows с работающим контейнером или панелью управления Docker.

- **Что должно быть прислано студентом:** Скриншот консоли после выполнения команды `git clone https://github.com/big-data-europe/docker-hive.git`.

- **Что проверить:** Убедитесь, что контейнеры успешно запущены. На скриншоте должна быть строка с сообщением о запуске сервисов без ошибок.
